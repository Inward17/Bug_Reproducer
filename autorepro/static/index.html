How a run works

  1. AnalyzeLLM

    Turns the report into steps, target elements and a success condition.

  2. InspectHTTP

    Fetches the page and extracts real selectors, so nothing is guessed.

  3. GenerateLLM

    Writes a Selenium script that checks for the buggy behaviour.

  4. ExecuteDocker

    Runs it in headless Chromium and captures screenshots.

  5. EvaluateLogic

    Decides the verdict and classifies any failure.

  6. RefineLLM

    Diagnoses the failure and rewrites the script for another attempt.
