THE VERDICT CONTRACT — the system reads exactly one line to decide the outcome:

  AUTOREPRO_RESULT {{"reproduced": <true|false>, "variant": "<which check matched>", "evidence": "<text you saw>"}}

Build it with json.dumps, print it exactly once, print it even when the bug was not
reproduced, and never hard-code `true`. Page text goes on its own line as
`print("PAGE_TEXT:", visible_text[:500])` and is never read as a verdict.

DIAGNOSIS GUIDE — read `error_type` in the execution result:

1. `BugNotObserved` — the script ran correctly and printed reproduced=false.
   → Your VERIFICATION CONDITION is wrong, not your mechanics. Read the PAGE_TEXT lines in
     the history: they show what the page really displays. Pick a DIFFERENT condition based
     on that actual text. Do not re-submit the same check with cosmetic changes.
   → Remember the bug IS the failure. For "login always fails", look for the error message
     ("Invalid", "incorrect"); do NOT look for a successful redirect.
   → Also consider that you may be acting on the wrong element, or not waiting long enough
     for the result to appear.

2. `WrongVerification` — the script exited cleanly but printed no AUTOREPRO_RESULT line.
   → Add the verdict line. It must run on every path, including when your checks all fail.

3. `Timeout` — an element was not found in time. The CSS selector is wrong.
   → Try different selectors: button[type='submit'], input[type='submit'], #submit, .btn-login
   → For input fields: input[name='username'], input[id='username'], input[type='text']

4. `ElementNotFound` — the element does not exist. Re-read the PAGE DOM section above and
   use a selector that actually appears there.

5. `NetworkError` / ERR_CONNECTION_REFUSED — the target could not be reached from the sandbox.
   → Do NOT change the URL. Keep EXACTLY: {target_url}
   → The networking is handled by the system. Fix other parts of the script, and make sure
     the verdict line is still printed so the run isn't silent.

6. `Unknown` with a NameError (e.g. 'json' is not defined) — you forgot an import.
   → Always import json and time.

7. `SecurityViolation` — you imported a module that is not allowed. You may only use:
   json, time, re, math, random, datetime and selenium.*.
